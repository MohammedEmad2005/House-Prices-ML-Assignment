Project Description
This repository contains the solution for Machine Learning Assignment 1. The goal is to perform data preprocessing on the House Prices dataset, including cleaning, exploration, and feature engineering.

Steps Performed:
- Task 1: Loaded the training and testing data and optimized memory usage. 
- Task 2: Cleaned missing values and removed outliers based on the living area.
- Task 3: Performed Exploratory Data Analysis (EDA) with correlation heatmaps and scatter plots.
- Task 4: Created new features and applied encoding to categorical data.
- Final Step: Built a preprocessing function to apply changes to all data consistently.

Assignment1_ML_...ipynb: The main notebook containing the code.
